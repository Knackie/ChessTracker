Ajouter une partie

Ce formulaire ajoute une partie dans assets/data/matches.json puis crée un commit GitHub via ton token.

Sécurité

Le token GitHub est utilisé uniquement pour l'appel API dans ton navigateur et n'est pas sauvegardé. Utilise un token à portée minimale (permissions "Contents: Read and write") et évite un poste non fiable.
